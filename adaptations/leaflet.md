## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference。正文按 Leaflet **1.9.4** 编写（2023-05 发布，至今仍是稳定版；npm 与 GitHub Release 一致）。按任务读三节：「核心 API」查 `L.map`/`L.tileLayer`/`L.geoJSON` 的选项表；「与 Vue / React 集成」拿生命周期写法；「常见问题」表的报错原文可直接对照定位。CSS 与 SRI 哈希只对 1.9.4 有效，改版本要连哈希一起换。数据源是 WMS/WFS 时用 `skill` 加载 `geoserver`，要更强投影与 MVT 能力用 `skill` 加载 `openlayers`。
- **执行环境**：`npm install`、`npm run build` 走 `ops_bash`（Windows 下是 MSYS bash），`Get-Command`、`Invoke-WebRequest` 这类 Windows 原生命令走 `pwsh`。正文用 `python -m http.server 5173` 起静态服务，Windows 上 `python` 不在 PATH 时改用 `py -3 -m http.server 5173`；起服务、`npm install` 都是长任务，用 `ops_bash` 的 `run_in_background` 跑，`job_output` 收日志、`job_kill` 收尾。三步以上（装包 → build → 起服务 → 截图核对）先 `todo_write`。没有 node 时用 `docker run --rm -v "$PWD:/w" -w /w node:22 bash -lc "npm i && npm run build"`。
- **先探测版本**：`npm ls leaflet` 看实际装到哪版，没装则 `npm view leaflet version`；页面里 `console.log(L.version)` 应为 `"1.9.4"`。差异点：正文明确 1.9.4 仍是当前稳定版，2.0 只有 beta（`v2.0.0-beta.3`，2026-11-10 发布）且 API/插件兼容性仍在变动，回答与示例默认给 1.9.4 方案，用户明确要试 2.0 时先说明是预发布、`npm view leaflet dist-tags` 核对 `next` 指向哪版；网上大量 1.7/1.8 教程；CDN 的 `integrity` 哈希与版本强绑定，把 1.9.4 的哈希贴到别的版本上会直接白屏。正文按 1.9.4 写的 API（如 `coordsToLatLng`、`L.Draw.Event`）在 1.6 前的插件里可能不同名。
- **验证产物**：正文给了明确验收：页面先出 OSM 底图 → 数据加载后视野收到点位范围 → 点圆点弹名称 → 右上角能切 POI。先在 `ops_bash` 里 `curl.exe -I http://localhost:5173/` 与入口 js 确认 200，再让浏览器打开页面，环境允许时截图并用 `read_image` 真看一眼瓦片、标记、控件都在位。判据是「图上看得见正确图层与弹窗」，不是构建退出码 0；SPA 里还要检查切路由后没有重复实例与内存增长。
- **风险与权限**：`npm install` 改依赖树、`npm run build` 覆盖 `dist/`、起服务占端口，都先 `ask_user_question` 给「只本地跑 / 用 Docker 沙箱跑 / 先不装」选项，别默认占 80 端口。天地图等瓦片服务的 `tk`、含 token 的底图 URL 不要硬编码进提交的前端代码；使用 OSM 必须保留 `attribution`，别把版权信息抹掉。
- **常见失败**：`Uncaught Error: Map container is already initialized.` 是同一容器 `L.map()` 两次（React StrictMode、热更新最常见），先 `map.remove()` 并把引用置空；`Map container not found.` 是 DOM 还没挂载；`L is not defined` 是脚本顺序或 CDN 失败；区域空白基本是容器没设 `height`；`invalidateSize()` 只在容器尺寸变化后调用；npm + 打包器下默认 marker 图标 404，要显式设置 `L.Icon.Default` 的 `iconUrl`/`iconRetinaUrl`/`shadowUrl`。坐标一律 `[lat, lng]`，GeoJSON 是 `[lng, lat]`，别混。
