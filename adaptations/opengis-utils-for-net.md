## DeepSeek Harness 使用建议

- **加载与引用**：主文件给 `OguLayerUtil` 入口、模型类与枚举；`OguLayerUtil`/`GeometryUtil`/`CrsUtil`/`ShpUtil`/`PostgisUtil`/`GtTxtUtil` 的完整签名在 `reference/util-classes.md`（开头 `## Contents` 按类分节，`read` 时带 `offset`/`limit`），从零构造图层、读写筛选的成段示例在 `reference/code-patterns.md`。主文件 480 余行，用 `grep` 搜 `ReadLayer(`、`CrsUtil.Transform`、`Geojson2Wkt` 定位行号再局部读，别整篇搬进上下文。
- **执行环境**：`dotnet new/restore/build/run/test` 走 `ops_bash`；确需 `Get-Command` 或带反斜杠的 Windows 路径参数时换 `pwsh`。探测工程建在会话工作区（`dotnet new console -o work/ogu-probe`），别写进 `assets/`。正文里的 `findstr` 是 cmd 写法，MSYS 下用 `grep`：`dotnet list package --include-transitive | grep OpenGIS.Utils`。GDAL 原生运行时由 `MaxRev.Gdal.Universal` 随包分发，不要手写 `GdalConfiguration.ConfigureGdal()`。长构建放后台作业，用 `job_output` 收日志。
- **先探测版本**：`dotnet --version`（库目标 .NET Standard 2.0，.NET Core 2.0+/5+ 均可引用），正文按 `OpenGIS.Utils` 1.1.2 编写；`dotnet restore` 能解析即包可用，`dotnet list package --include-transitive | grep OpenGIS.Utils` 核对实际解析到的 1.1.2。`NU1101`/`NU1102` 表示源或版本不可用，如实报告，不要自行改版本号重试。低于 1.1.2 的版本没有 `GEOPACKAGE`/`KML`/`DXF` 这些 `DataFormatType` 与 `ConvertFormat`。
- **验证产物**：`dotnet build` 成功只说明编译过，GDAL 原生库是运行期才加载。写最小控制台跑正文「典型工作流」：读 Shapefile 后打印 `layer.Wkid` 与 `layer.GetFeatureCount()`，`CrsUtil.Transform` 逐要素转到 4528 并改 `layer.Wkid`，`WriteLayer` 出 GeoPackage 后回读，核对 WKID 为 4528、要素数与筛选结果一致；`dotnet run > run.log 2>&1` 再 `read` 日志确认，机上有 GDAL 时补 `ogrinfo -so data/parcels_4528.gpkg`。成品用 `present` 交付。
- **风险与权限**：`WriteLayer` 写 Shapefile/GeoPackage/KML 会覆盖同名文件，先换名或备份；`ConvertFormat` 同理。PostGIS 连接串与 GDAL 配置里的密码不要回显，连生产库前用 `ask_user_question` 给「只读/新库/跳过」选项。`dotnet restore`、装 SDK、改 `NuGet.config` 前先问用户。`OgrGeometry` 实现 `IDisposable`，用完 `Dispose()`，否则大批量几何会吃满内存；`GEOTOOLS` 在 .NET 版被重定向到 GDAL，别据此以为有纯托管路径。
- **常见失败**：`DllNotFoundException` / `Unable to load DLL 'gdal'` 多是 RID 与运行环境不一致，`dotnet publish -r win-x64` 后跑发布目录，别跑 `bin/Debug`；`Geojson2Wkt` 传整份 FeatureCollection 文件内容会抛 `ArgumentException`，整文件走 `OguLayerUtil.ReadLayer`；GBK Shapefile 乱码先 `Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)` 再传 `Encoding.GetEncoding('GBK')`；`CrsUtil` 只有 WKT/`OgrGeometry` 重载，没有整层变换方法。
