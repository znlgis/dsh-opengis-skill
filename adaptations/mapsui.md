## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference。正文按 Mapsui **5.1.0**（net8.0 / net9.0，上游 5.2.0-beta.1 为预发布不计入）编写。按任务读：「安装」确认 UI 包与数据源包的组合、「WPF 入门」拿最小可运行工程、「核心概念」区分 Map/Layer/Provider、「WMS」一节的 `WmsProvider.CreateAsync` 是 5.x 硬要求、「常见问题」表覆盖空白 MapControl 与中文乱码。几何细节用 `skill` 加载 `nettopologysuite`，服务端发布用 `skill` 加载 `geoserver`，别去读兄弟目录的 SKILL.md。
- **执行环境**：`dotnet` 命令走 `ops_bash`（Windows 下是 MSYS bash），需要看 Windows 原生产物时用 `pwsh`。先探测 `dotnet --list-sdks`：5.1.0 只支持 net8.0/net9.0（`Mapsui.Wpf` 是 net8.0-windows/net9.0-windows），只有 .NET 6/7 的机器必须先装 SDK，不能指望改个 target framework 就编译过。`dotnet add package` 与首次 `dotnet restore` 会拉 NuGet 包，属长任务，用 `ops_bash` 的 `run_in_background` 跑、`job_output` 收日志；本机没有 SDK 时退回 `docker run --rm -v "$PWD:/w" -w /w mcr.microsoft.com/dotnet/sdk:9.0 dotnet build`。新建工程 → 加包 → 编译 → 无头渲染是三步以上，先 `todo_write`。
- **先探测版本**：`dotnet --list-sdks` 与 `dotnet list package` 确认 `Mapsui.Wpf`/`Mapsui.Nts`/`Mapsui.Tiling` 是否都是 5.1.0——正文强调所有 `Mapsui.*` 子包版本必须一致，混版会在运行时抛类型加载异常，编译期看不出来。差异点：5.x 起 WMS 必须用异步工厂 `WmsProvider.CreateAsync`，正文工作流 2 里还留着一处同步 `new WmsProvider(...)` 的旧写法，5.1 上不可用，以「WMS」一节的 `CreateAsync` 为准；WPF 的 NuGet 包名是 `Mapsui.Wpf`，程序集/命名空间仍是 `Mapsui.UI.Wpf`，网上 v2 教程的包名会装不上。
- **验证产物**：`dotnet restore`/`dotnet build` 通过只说明编译过，正文已明确要求用 `Mapsui.Rendering.Skia.MapRenderer` 把 `map` 渲染成 PNG（参数以 IntelliSense 为准，常见做法是 `RenderToBitmapStream` 写 MemoryStream 再落盘），然后用 `read_image` 真看一眼：底图瓦片有没有、点位是否在预期位置、WMS 层是否出现。桌面窗口本身 AI 看不到，需请用户运行后截图。空白的地图 PNG 与「渲染成功」是两件事，只凭 build 退出码 0 报告成功属于假验证。
- **风险与权限**：新建 .NET 工程、装 NuGet 包、运行桌面程序都会改用户机器状态，先 `ask_user_question` 给「只新建到指定目录 / 用 Docker 构建 / 先不建」选项。连接 PostGIS 或私有 WMS 的密码、token 不要写进代码或回答，改用环境变量或用户机密存储；`Map.ZoomToExtents()` 在无数据图层上会让视图缩到无效范围，别对空 map 调用。
- **常见失败**：窗口空白先查有没有执行 `MapControl.Map = map`，再查 NuGet 里是否缺 `Mapsui.Wpf`；MAUI 空白查 `MauiProgram` 里 `UseSkiaSharp()` 与 `UseMapsui()` 是否注册；点跑到南太平洋是漏了 `SphericalMercator.FromLonLat(lon, lat)`（视图坐标系是 EPSG:3857）；Shapefile 中文乱码是 DBF 缺 `.cpg`，用 `new ShapeFile(path, true) { Encoding = ... }` 属性赋值而非构造参数；找不到 `GeometryFeature` 装 `Mapsui.Nts`，找不到瓦片类型装 `Mapsui.Tiling`。
