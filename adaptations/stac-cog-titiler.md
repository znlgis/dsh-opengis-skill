## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，没有 reference 目录；正文「核心概念与命令」的 COG/STAC/TiTiler 三段与「典型工作流」三条链路是主线，「常见问题」按症状查。COG 侧命令与校验的通用细节用 `skill` 加载 `gdal`，pgstac 的库侧知识用 `postgis`，前端消费 TileJSON 用 `maplibre-gl-js`；不要 `read` 兄弟目录的 SKILL.md。
- **执行环境**：Python 依赖装进会话工作区的 venv（`python -m venv .venv` 后 `.venv/Scripts/python -m pip install ...`，MSYS bash 里路径写 `/d/work/.venv/Scripts/python.exe`）。不要拿 `load_workspace_dependencies` 返回的随包 Python 试 `import rasterio`：那套解释器有 numpy/Pillow，但没有 GDAL/rasterio 绑定，`rio cogeo` 直接起不来。Windows 没有系统 GDAL 时装 conda-forge（`conda install -c conda-forge gdal rio-cogeo`）或跑官方镜像。`uvicorn` 与 docker 起的 TiTiler 都是常驻服务，必须 `run_in_background`，`job_output` 读到 `Uvicorn running on http://127.0.0.1:8000` 再发请求，收尾 `job_kill`；起服务前先 `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8000/` 探端口。
- **先探测版本**：`rio cogeo --version` 应为 7.0.4，`python -c "import rasterio; print(rasterio.__version__, rasterio.__gdal_version__)"` 一次确认绑定与底层 GDAL 都在，`python -c "import titiler.core, stac_fastapi.api as m; print(titiler.core.__version__, m.__version__)"` 对 2.4.0 与 7.1.1。`pip install titiler` 装出来是停在 0.25.0 的旧元包、入口完全不同，看到这个版本号就卸掉改装 `titiler.application==2.4.0`；正文要求 Python >= 3.11，`python -V` 低于就先换解释器。
- **验证产物**：COG 以 `rio cogeo validate output_cog.tif` 的返回内容为准（要 valid），再 `rio cogeo info output_cog.tif` 看 overviews 与 blocksize。服务用 `curl -s -o tile.png -w '%{http_code} %{content_type} %{size_download}\n'` 打 `/cog/tiles/WebMercatorQuad/8/210/98.png?url=...`，必须 200 + `image/png` + 非零字节，再用 `read_image` 看瓦片不是全黑或全透明（bidx 与 rescale 错位就长这样）。对象存储的 Range 能力单独验：`curl -s -r 0-1023 -o /dev/null -w '%{http_code}' <cog-url>` 要 206，回 200 说明 CDN 忽略了 Range，后续 416 与出图慢都从这里来。
- **风险与权限**：对象存储凭据只放环境变量（`AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` 由外部注入，命令里只引用变量名），不写进脚本、不贴进汇报；pgstac 迁移要超级用户且会改库结构，连生产库前用 `ask_user_question` 确认。对外暴露 8000/8080、把 COG 传到第三方桶、发布别人的影像之前确认许可，STAC 只描述数据、不改变版权；`cogeo-mosaic create` 会覆盖同名 `mosaic.json`，先换名输出。
- **常见失败**：416 是文件没按 tile 组织或被截断，回 `rio cogeo validate` 重转；瓦片全黑先查 `bidx` 顺序与 `rescale`，单波段没拉伸也会全白；403 是服务进程没拿到桶凭据，改用预签名 URL 或配 IAM；`/stac/tiles` 400 多为 `url` 没做 URL 编码或 `assets` 键名与 Item 不符，先 `curl` 打开 Item JSON 核对。
