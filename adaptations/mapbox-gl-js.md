## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference。正文按 mapbox-gl **3.34.2** 编写，按任务读：「环境准备」讲 token 获取与 npm/CDN 两路；「核心 API」的 Map 初始化、addSource、addLayer 表达式、3D 地形、交互事件是最常改的几节；「常见问题」表里的报错原文可直接对号入座。v2 起是 Mapbox 专有许可（v1.x 才是 BSD-3），用户要开源或零成本时直接 `skill` 加载 `maplibre-gl-js`——本库 v1 的开源分支，免 token、BSD-3-Clause、API 高度兼容，正文给了迁移路径，别默认用 Mapbox 托管的 `mapbox://` 样式。简单瓦片场景用 `skill` 加载 `leaflet`，投影与 MVT 高级需求用 `skill` 加载 `openlayers` 对比，瓦片源用 `skill` 加载 `geoserver` 自建。
- **执行环境**：`npm install`、`npm run build` 走 `ops_bash`（MSYS bash），Windows 原生命令走 `pwsh`；正文提到 Windows 下用 `npm.cmd`。`npm install mapbox-gl` 与打包都是长任务，用 `ops_bash` 的 `run_in_background` 跑、`job_output` 收日志、`job_kill` 收尾；静态预览用 `npx serve dist` 也是常驻进程，同样走后台作业。没有 node 时用 `docker run --rm -v "$PWD:/w" -w /w node:22 bash -lc "npm ci && npm run build"`。三步以上（装包 → 建图 → build → 浏览器核对）先 `todo_write`。
- **先探测版本**：`npm ls mapbox-gl`（没装则 `npm view mapbox-gl version`），CDN 的 JS 与 CSS 必须同为 `v3.34.2`——正文要求固定版本号，混版本会样式失效；控制台里 `map.isStyleLoaded()` 与 `load` 事件可确认运行时真的起来了。差异点：v3 提供 `mapbox-gl/esm` 小体积入口，v2 没有；v2+ 才需要 access token 并受 TOS 约束，v1 是 BSD。写 `^3.34` 会拉到更新的 3.x，行为可能与正文示例不一致，生产要锁精确版本。
- **验证产物**：`npm run build` 通过不是验证。`npx serve dist` 起服务后 `curl.exe -I http://localhost:5173/` 与入口 js 应为 200，再在浏览器打开看底图是否渲染、有没有 `api.mapbox.com` 的 401、图层与地形是否出现；环境允许时截图并用 `read_image` 真看一眼。无浏览器环境下如实说明「未做渲染验证」，不要用构建成功冒充地图可用。若用到 `setTerrain`，看图确认地形起伏与 DEM `encoding` 对得上。
- **风险与权限**：v2+ 受 Mapbox TOS 约束按量计费（免费额度以官方 pricing 页为准），调用前用 `ask_user_question` 说明可能产生费用并给「改用 MapLibre / 用测试 token 小流量验证 / 直接上生产」选项。前端只能放 `pk.` 公开 token，`sk.` 绝不能进构建产物：提交前用 `grep` 搜 `sk.` 与硬编码 `pk.`，日志与回答里不要回显 token；装包、起 dev server 前先确认。
- **常见失败**：401 / `A valid Mapbox access token is required` 查 token 前缀、撤销状态、URL restrictions 与配额；`Style is not done loading` 是在 `load` 前调了 `addSource`/`addLayer`，移进回调；空白先查容器 `height` 与 `map.resize()`；`mapboxgl is not defined` 是 CDN 顺序或 JS/CSS 版本不一致；点击无反应查图层 id 与 `source-layer` 名；feature-state 悬停不生效是要素缺 id（矢量源设 `promoteId`）；SPA 卸载别忘 `map.remove()`。
