## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference；部署方式看「环境准备」（Debian 包 / OSGeo4W / Docker），请求示例看「核心 API / 命令」，变量与排查看「服务端环境变量」「常见问题」。服务端插件逻辑与项目自动化用 `skill` 加载 `pyqgis`，另一套 OGC 方案加载 `geoserver`，数据源侧加载 `postgis`。
- **执行环境**：`docker`、`curl.exe` 走 `ops_bash`（Windows 是 MSYS bash），原生 Windows 写法与 `$env:` 变量走 `pwsh`，多步编排可用 `run_code` 串起来。服务端部署在 Linux/容器，本机是 Windows 会话，所以默认路径是 Docker：`docker run -d --name qgis-server ... qgis/qgis:ltr` 起容器再用 `curl`（Windows 下必须写 `curl.exe`）打请求，容器与端口用 `ops_bash` 的 `run_in_background` 起、`job_output` 收日志、`job_kill` 停容器。正文的 `sudo apt install qgis-server`、`/usr/lib/cgi-bin/qgis_mapserv.fcgi`、Apache/Nginx 片段都是目标服务器写法，本机会话改不了远端主机，要么在主机上执行，要么全部在容器里验证；OSGeo4W 路线在本机装 `QGIS Desktop + QGIS Server + apache + mod_fcgid` 后才可用。`SetEnv`/`fastcgi_param` 属于服务器配置，别当本地命令跑。
- **先探测版本**：正文按 QGIS Server 4.2.3（最新）与 LTR 3.44.15 编写。先确认服务端版本：`qgis --version`、`qgis_process --version`、`dpkg -l qgis-server` 或看镜像 tag；生成项目的 QGIS Desktop 与服务端应同一主版本，否则旧项目可能打不开。直接执行 `qgis_mapserv.fcgi`（无参数）在 Linux 上应返回含 `ServiceExceptionReport` 的 XML，这是「装上且能跑」的最低判据，Windows/Docker 下用功能更全的 `GetCapabilities` 代替。
- **验证产物**：`curl.exe -sS "http://localhost/cgi-bin/qgis_mapserv.fcgi?MAP=/data/world.qgz&SERVICE=WMS&VERSION=1.3.0&REQUEST=GetCapabilities" -o caps.xml` 存盘后 `grep -n "<Layer>" caps.xml` 核对图层清单（名字、CRS、样式），确认不是空文档或异常报告；再发 `GetMap` 拿 PNG 用 `read_image` 真看一眼是否空白、范围是否正确，`GetFeature` 取 GeoJSON 检查要素字段。只看到 HTTP 200 不算通过，正文明确 `GetMap` 的 500/空白要回查 `MAP` 路径可读性、图层 `published` 勾选与 CRS/`BBOX`。
- **风险与权限**：启动容器、映射 80 端口、改 Web 服务器配置、把服务暴露到非回环地址之前必须用 `ask_user_question` 让用户确认（尤其本机已有 Apache/Nginx 占用端口时）；工程文件可能含数据库连接串与口令，命令行、日志与回复里不要回显，二进制用 `QGIS_PROJECT_FILE` 环境变量引用而不是把密码拼进 URL。`GetPrint` 在无 X 的 Linux 上要 `Xvfb`（`DISPLAY=:99`），别指望它直接出图；`QGIS_SERVER_LOG_FILE` 已废弃，统一 `QGIS_SERVER_LOG_STDERR=1` 交给日志系统。
- **常见失败**：`Service unknown or unsupported` 不是服务坏了，而是缺 `SERVICE`/`MAP` 参数；`GetCapabilities` 里图层名是长 ID 说明项目开着「Use layer ids as names」；中文乱码设 `QGIS_SERVER_OVERRIDE_SYSTEM_LOCALE=en_US.UTF-8`；WFS `Transaction` 必须 POST 且数据源可写；`QGIS_SERVER_*` 改动要重启 FCGI 进程或容器才生效，改了没反应先确认进程真的重启过。
