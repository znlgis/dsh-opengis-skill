## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference；正文按 DuckDB 2.0.0 + spatial 扩展编写，函数签名查「核心 API」各表，读文件参数查「ST_Read 常用参数」表，「常见问题」里的报错原文可直接当定位线索。与 GeoPandas 互转用 `skill` 加载 `geopandas`，落盘格式与投影细节用 `skill` 加载 `gdal` 和 `proj`，不要在技能之间 `read` 兄弟目录。
- **执行环境**：`pip install duckdb==2.0.0` 或官方 CLI 走 `ops_bash`；扩展装到用户目录 `~/.duckdb/extensions/<version>/<platform>/`（Windows 上是 `%USERPROFILE%` 下的同名目录），离线环境整目录拷过来即可。大批量 `ST_Read` 加空间 join（正文明确 GDAL 单线程、DuckDB 无 R-Tree）用后台作业跑，`job_output` 收进度，跑偏了 `job_kill`；写 SQL 前先 `todo_write` 列出「验扩展 → 落表 → 投影 → 叠加 → 回读」。
- **先探测版本**：`SELECT duckdb_version()` 拿库版本；正文按 2.0.0 编写，`ST_Area_Spheroid`、`ST_CoverageUnion_Agg` 属较新函数，低版本没有，写例子前先用 `SELECT function_name FROM duckdb_functions() WHERE function_name LIKE 'ST_%'` 探测实际可用集合。`duckdb_extensions()` 里 spatial 的 `loaded` 必须为 true 才算就绪，`extension_version` 随 DuckDB 版本自动匹配、没有独立版本号，报版本对不上时先核对 DuckDB 本身。
- **验证产物**：写完 Parquet 立刻回读，先按 `SELECT count(*), ST_GeometryType(geometry), ST_IsValid(geometry) ...` 分组看类型与无效几何分布，再看 `ST_XMin`、`ST_YMax` 是否落在预期 CRS 的合理范围；MVT 用 `ST_AsMVTGeom` 裁剪后检查空几何比例，别把全空的瓦片当成功。`ST_AsWKB` 只写几何、不写 CRS，输出给下游前要确认投影已记录，命名带步骤前缀，失败时能按步回滚。
- **风险与权限**：`COPY ... TO`、`CREATE OR REPLACE TABLE`、`DROP TABLE` 与 `INSTALL spatial`（联网下载）都可能改盘或改环境，执行前用 `ask_user_question` 确认目标路径与是否可覆盖，优先写新文件名；连生产库或挂载共享目录时不要回显连接串与凭据，也不要在答案里贴完整 DSN。
- **常见失败**：`Extension spatial is not installed` 是只 `LOAD` 没 `INSTALL`，或离线环境拉不到扩展；`Catalog Error: Scalar Function with name ST_Intersects does not exist` 是新连接忘了 `LOAD spatial`，每个连接都要重新 LOAD；`ST_Area` 返回 0 或极小数是经纬度单位“平方度”，改 `ST_Area_Spheroid` 或先 `ST_Transform`；空间 join 极慢就先用 `ST_Intersects_Extent` 粗筛。
