## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference；正文按 GRASS GIS 8.5.0（8.4 LTR 最新补丁 8.4.2）编写，按任务跳「grass 启动器与无头执行」「g.region 计算区域管理」「数据导入导出」，Python 脚本化看「Python 脚本化」一节。本技能几乎不需要 `read` 参考文件，但和 `gdal`（`r.out.gdal` 后的格式与元数据核对）、`qgis-process` 经常连用，用 `skill` 按名加载，别去读兄弟目录的 SKILL.md。
- **执行环境**：命令走 `ops_bash`（Windows 下是 MSYS bash）。正文的 `sudo apt install grass` 在 Windows 不存在：先探测 `grass --version`，没有就走 OSGeo4W 安装器（装好后在 OSGeo4W Shell 里用），或 `conda install -c conda-forge grass`，再不行 `docker run --rm -v "$PWD:/data" -w /data osgeo/grass-gis:latest grass ...`（容器内路径写 `/data`，别把 `D:\\...` 传进去）。`$HOME/grassdata` 换成会话工作区里的固定目录，避免每次换路径。正文 `--exec sh -c '...'` 的多行引用在 Windows 上不可靠，改写成单个 `.py` 脚本再用 `grass --tmp-project EPSG:3857 --exec python3 analysis.py`。整条地形分析链（import → slope → 导出）是长任务，用 `ops_bash` 的 `run_in_background` 跑，`job_output` 看日志。8.5 一个地图集可存多份掩膜，`r.mask.status` 查当前掩膜；Python 里切区域/掩膜用 `gs.RegionManager`/`gs.MaskManager` 上下文，退出自动还原，别手工 `g.region -d` 猜状态。
- **先探测版本**：`grass --version` 拿到实际版本，再跑 `grass --tmp-project EPSG:3857 --exec g.version -rge` 确认能起无头会话。正文按 8.5.0 编写：8.5 要求 GDAL 3.7+、PROJ 9.0+、Python 3.10+（`g.version -rge` 输出里能读到 gdal/proj 实际版本，低于要求先升级依赖而不是怀疑数据）；`grass.tools` 是 **8.5 新增**且官方标为实验性（预计 8.6 稳定），生产脚本先留在 `grass.script`，`ImportError` 就是版本不够，8.4.x/LTR 上只能用 `run_command`/`parse_command`；`--tmp-project` 在老 7.x 叫 `--tmp-location`，命令名不同。Docker 镜像标签形如 `8.5.0-ubuntu`，与本机版本不一致时先对齐再抄命令。
- **验证产物**：`--tmp-project` 内的地图结束时随目录删除，必须先在脚本里 `r.out.gdal input=slope output=/work/slope.tif format=GTiff --overwrite` 导出，再用 `gdalinfo -json slope.tif` 核对 CRS、行列数、NoData 与范围；会话内核对用 `g.region -p format=json`（确认 rows/cols/res 符合预期）和 `g.list type=raster format=json`；8.5 起 `r.univar`/`r.stats`/`v.info` 等大量模块支持 `format=json`，脚本里一律 `gs.parse_command(..., format="json")` 取 dict，不要 `grep` 人类可读表格——列宽会随 locale 变。出图类结果（`d.rast` 转 PNG 或 gdal 渲染）用 `read_image` 真看一眼不是空白。判定依据是数值对得上，不是「模块没报错」。
- **风险与权限**：`--overwrite`、`g.remove`、`g.rename`、`t.connect` 会改或删地图集数据，`t.rast.aggregate` 覆盖已有 strds 同理；这些操作先 `ask_user_question` 给「换新名字 / 先备份地图集 / 直接覆盖」三选项。Docker 里结果文件属主是 root，`--user=$(id -u):$(id -g)` 加 `--env HOME=/data/` 之前确认写入路径。时空数据库按地图集独立，连错地图集会看到空数据集而不是报错。
- **常见失败**：`Exec format error` 是 `--exec` 脚本缺 shebang 或没有可执行权限；`GISBASE not defined` 说明 Python 在 GRASS 会话外跑，改用 `grass --exec python3` 或先 `gs.setup.init(...)`；`Raster map <x> not found` 先用 `g.list type=raster` 确认地图名与地图集；结果范围或分辨率不对几乎总是 `g.region` 没设对。模块错误以 `ERROR:` 或 `WARNING:` 开头并回非零码，按第一条真实错误定位。
