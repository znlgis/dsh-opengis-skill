## DeepSeek Harness 使用建议

- **加载与引用**：单文件技能，无 reference。正文按 MapServer **8.6.6** 编写，按任务读：「核心 API / 命令」的 mapfile 对象层次与最小示例、「mapserv CGI 请求参数」「WMS / WFS 请求示例」；样式问题看「SLD 绑定」；「常见问题」表里 `No query information to decode`、空白 GetMap 等原文可直接对号。数据准备用 `skill` 加载 `gdal`（`ogr2ogr`），PostGIS 源用 `skill` 加载 `postgis`，需要 WFS-T 写入时正文已指出 MapServer 只读，应改用 GeoServer。
- **执行环境**：命令走 `ops_bash`（Windows 下是 MSYS bash），Windows 原生命令与 OSGeo4W 的 `mapserv.exe` 走 `pwsh`。正文的 `sudo apt install cgi-mapserver` 在 Windows 不存在：先探测 OSGeo4W 安装目录下有没有 `bin/mapserv.exe`，没有就用 OSGeo4W 安装器勾选 `mapserver` 组件（官方给的就是这条路），或 `docker run --rm -v "$PWD:/data" -w /data ghcr.io/osgeo/mapserver:latest mapserv -v`。源码编译那段的 `tar -zxvf` 在 `pwsh` 里换成 `Expand-Archive`，`make install` 为目标目录时先确认写权限。启动 FastCGI/Apache 常驻服务是长任务，用 `ops_bash` 的 `run_in_background`，`job_output` 收日志、`job_kill` 收尾。
- **先探测版本**：`mapserv -v` 一次拿到版本与 `SUPPORTS=` 列表——正文按 8.6.6 编写，输出里要有 `MapServer version 8.6.6` 且 `SUPPORTS` 含所需的 `WMS_SERVER`/`WFS_SERVER`，缺项说明这份构建根本没编进该库，改 mapfile 无用。差异点：WFS 默认不输出要素属性是 MapServer 4.6 起就有的默认行为（不是 8.x 新增），要属性必须配 `gml_include_items`，老教程里 WFS 直接有属性的写法会「字段全空」；`wms_enable_request` 不设则不启用任何请求。8.0 起 `shp2img` 更名为 `map2img`，用 `command -v map2img` 确认离线渲染工具在，照抄旧教程的 `shp2img` 会直接报命令不存在。
- **验证产物**：三级验证，缺一不可。先离线渲染 `map2img -m demo.map -o out.png -s 600 400`，用 `read_image` 真看一眼 out.png 有图、范围与配色对；再 `mapserv -nh "QUERY_STRING=map=/abs/demo.map&SERVICE=WMS&VERSION=1.1.1&REQUEST=GetCapabilities"` 抓能力文档，确认图层名、`wms_srs` 与格式都在；最后 `curl.exe -s -o get.png -w "%{http_code} %{content_type}"` 发一次 `GetMap` 确认 200 和 `image/png`。判据是能力文档与实际出图一致，不是 `mapserv` 进程起来了。
- **风险与权限**：`map=` 参数可读服务器任意路径，是 MapServer 最典型的误配置——上线前必须设 `MS_MAP_PATTERN`/`MS_MAP_NO_PATH` 或用包装脚本；把 `wms_enable_request` 设为 `*` 等于对全网开放包括 `GetFeatureInfo`。重启 Apache/nginx、改 CGI 目录权限（`chmod o+x` 在 Windows 无对应语义，改用 IIS/FastCGI 配置）、覆盖生产 mapfile 前，用 `ask_user_question` 给「先备份 mapfile / 只改测试环境 / 直接生效」选项。
- **常见失败**：`No query information to decode` 只说明 CGI 能执行，缺的是 `SERVICE`/`REQUEST` 参数；GetMap 空白图查 `EXTENT` 与请求 `BBOX` 是否重合、`PROJECTION` 与数据是否一致、图层 `STATUS ON`；WFS 缺属性补 `gml_include_items "all"`（默认不输出属性是 4.6 起的默认行为，不是 8.x 才变）；`shp2img: command not found` 就是撞上 8.0 改名，换 `map2img`；SLD 不生效是 `NamedLayer/Name` 与图层 `NAME` 不匹配或 `CLASSITEM` 字段名错；中文注记方框查 mapfile 是否 UTF-8 与 `FONT` 中文字体。改一处只验一处（改 METADATA 只跑能力文档，改样式只跑 `map2img`）。
